# Delicious Bites Restaurant Website

A responsive restaurant website built using HTML, CSS, and JavaScript, featuring a dynamic food menu, category filters, shopping cart, and contact form.

## 🌐 Live Demo

**[Click here to visit Delicious Bites Restaurant Website](https://arya-gunji.github.io/Delicious-Bites-Restaurant-website/)**

## 💻 Source Code

[View the project on GitHub](https://github.com/Arya-gunji/Delicious-Bites-Restaurant-website)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## ✨ Features

- Responsive restaurant website design
- Dynamic food menu with category filters
- Shopping cart with quantity controls
- Cart subtotal, tax, and total calculation
- Contact form with input validation
- Customer testimonials
- Scroll-to-top button

## 🚀 How to Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
