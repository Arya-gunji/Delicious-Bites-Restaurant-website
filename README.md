# 🍽️ Delicious Bites Restaurant Website

A responsive and interactive restaurant website built using HTML, CSS, JavaScript, and Bootstrap. It allows visitors to explore the food menu, filter dishes by category, manage a shopping cart, read customer testimonials, and contact the restaurant.

## 📖 About the Project

Delicious Bites is a restaurant website designed to provide an attractive and user-friendly online browsing experience. The website presents restaurant information, food items, customer testimonials, and contact details in an organized layout.

The project demonstrates front-end web development concepts, including responsive design, dynamic content rendering, JavaScript event handling, DOM manipulation, shopping cart operations, and form validation.

## 🖥️ Website Sections

### 1. Home Section

The Home section welcomes visitors with the restaurant name, an introductory message, and an Explore Menu button.

**Features:**
- Restaurant introduction.
- Attractive hero section.
- Navigation to the menu.

[Open Home Section](https://arya-gunji.github.io/Delicious-Bites-Restaurant-website/#home)

### 2. Menu Section

The Menu section displays food items dynamically using JavaScript.

**Features:**
- Displays restaurant menu items.
- Filters dishes by category.
- Includes All, Appetizers, Main Courses, Desserts, and Beverages filters.

[Open Menu Section](https://arya-gunji.github.io/Delicious-Bites-Restaurant-website/#menu)

### 3. About Us Section

This section introduces the restaurant and explains its focus on fresh ingredients, food quality, and hospitality.

**Features:**
- Restaurant introduction.
- Information about food quality.
- Highlights of the dining experience.

[Open About Section](https://arya-gunji.github.io/Delicious-Bites-Restaurant-website/#about)

### 4. Statistics Section

The Statistics section presents restaurant-related figures in a visual format.

**Displayed statistics:**
- Years of experience.
- Menu items.
- Happy customers.
- Expert chefs.

[Open Statistics Section](https://arya-gunji.github.io/Delicious-Bites-Restaurant-website/#stats)

### 5. Customer Reviews Section

This section displays customer testimonials to present feedback about the restaurant experience.

**Features:**
- Customer review cards.
- Star ratings.
- Customer names and feedback.

[Open Customer Reviews](https://arya-gunji.github.io/Delicious-Bites-Restaurant-website/#testimonials)

*Note: The displayed testimonials are sample website content, not independently verified customer reviews.*

### 6. Contact Us Section

The Contact section provides restaurant contact information and a form for visitors to enter their details and message.

**Features:**
- Restaurant address.
- Phone number.
- Email address.
- Name and email input fields.
- Message field with form validation.

[Open Contact Section](https://arya-gunji.github.io/Delicious-Bites-Restaurant-website/#contact)

*The current front-end form validates input but does not send messages to a server or email inbox.*

### 7. Shopping Cart

The Shopping Cart allows visitors to review the items they select from the menu.

**Features:**
- Add food items to the cart.
- Increase or decrease item quantities.
- Remove items from the cart.
- Calculate subtotal, tax, and total.
- View cart items in a modal window.
- Display the cart item count.

Visitors can open the cart using the shopping cart icon in the navigation bar.

### 8. Footer Section

The Footer appears at the bottom of the website.

**Features:**
- Copyright information.
- Social media icon links.
- Additional page information.

### 9. Scroll-to-Top Button

The website includes a button that allows visitors to return to the top of the page quickly.

## 📂 Project Structure

```text
Delicious-Bites-Restaurant-website/
│
├── index.html
├── style.css
├── script.js
├── menu-data.js
├── utils.js
```

### File Descriptions

- **index.html** — Contains the website structure and main sections.
- **style.css** — Contains website styling, layouts, and visual effects.
- **script.js** — Handles menu interactions, cart functionality, form validation, and other JavaScript behavior.
- **menu-data.js** — Contains the menu data used by the application.
- **utils.js** — Contains reusable utility functions.
- **README.md** — Documents the project, features, and setup instructions.

## 🚀 How to Run Locally

### Prerequisites

- A modern web browser.
- Git, or the option to download the repository as a ZIP file.

### Step 1: Clone the Repository

```bash
git clone https://github.com/Arya-gunji/Delicious-Bites-Restaurant-website.git
```

### Step 2: Open the Project

```bash
cd Delicious-Bites-Restaurant-website
```

### Step 3: Run the Website

Open `index.html` in your browser.

For local development, you can also use the Live Server extension in Visual Studio Code.
